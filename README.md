# m5-clawbot

Custom ESP-NOW StackChan robot + handheld remote firmware.

## Layout

- **`robot/`** — StackChan receiver firmware (M5Stack CoreS3). ESP-NOW receiver, servos, avatar face, mic/speaker, camera, Tailscale/WireGuard gateway link (MicroLink). Built on ESP-IDF.
- **`remote/`** — Handheld remote firmware (M5StickC Plus + Hat Mini JoyC). Reads the JoyC stick, drives the robot over ESP-NOW. Built on ESP-IDF.

## Robot (`robot/`)

ESP-IDF project. Bundled components under `robot/components/`:
- `esp-openclaw-node`, `esp-openclaw-node-provisioning` — node runtime + provisioning
- `M5GFX`, `M5Unified`, `esp32-camera` — hardware libs
- `third_party/microlink/` — WireGuard/Tailscale tunnel

```
cd robot
idf.py set-target esp32s3
idf.py build flash monitor
```

## Remote (`remote/`)

ESP-IDF project for the M5StickC Plus.

```
cd remote
idf.py build flash monitor
```

### JoyC read (important)

The remote reads the Hat Mini JoyC over I2C **axes-only** (`0x00` X + `0x02` Y). It does **not** poll the button register `0x30` per-cycle — that wedges the freshly-booted JoyC STM32. OPERATE-down (mic PTT) is derived from the Y axis, not the stick click. Keep it that way.

## Notes

`build/`, `managed_components/`, and `sdkconfig` are gitignored (regenerated by ESP-IDF). Run `idf.py reconfigure` after cloning to pull managed deps.
